# Transjakarta Public Transportation Dummy Transaction Analysis – April 2023

Conducted transaction data analysis to understand passenger behavior patterns and support Transjakarta operators in improving operational efficiency and passenger experience. In this project, I was involved in the end-to-end analysis process, including gathering business requirements, data cleaning, exploratory data analysis, statistical analysis, and developing interactive dashboards using Tableau. The tools used in this project include VS Code, Tableau, Notion, and Canva.
